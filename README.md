# 박효균 — 포트폴리오

> 만든 게 아니라 내보냈다. 2026년에 실제로 배포한 일곱 개의 서비스.

빌드 도구 없는 정적 페이지 하나입니다. `index.html`이 전부이고, 배경은 외부 라이브러리 없이 직접 작성한 WebGL 프래그먼트 셰이더입니다.

## 구조

```
index.html    페이지 전체 (스타일·스크립트·이미지 인라인)
media/        실행 데모 영상 (손안의여름·탁카·데브핏)
```

이미지는 data URI로 포함돼 있어 요청이 한 번뿐입니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 열면 일부 브라우저에서 WebGL 컨텍스트가 막히므로 서버로 여는 편이 낫습니다.

## 만든 방식

- 배경 — fbm 노이즈 기반 셰이더. 마우스 위치가 광원, 스크롤과 무관하게 계속 흐릅니다.
- 히어로 — 세 줄이 마스크 안에서 시차를 두고 올라옵니다.
- 프로젝트 — 세로 스크롤을 가로 이동으로 바꾸고, 중앙에서 멀어진 카드는 기울고 어두워집니다.
- `prefers-reduced-motion`이 켜져 있으면 모든 모션을 끄고 세로 정적 레이아웃으로 바뀝니다.
