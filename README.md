# 박효균 — 포트폴리오

> 만든 게 아니라 내보냈다. 2026년에 실제로 배포한 열여섯 개의 서비스.

빌드 도구 없는 정적 페이지 하나입니다. `index.html`이 전부이고, 배경은 외부 라이브러리 없이 직접 작성한 WebGL 프래그먼트 셰이더입니다.

## 구조

```
index.html    페이지 전체 (스타일·스크립트 인라인)
js/cosmos.js  3D 궤도 (three.js, 첫 페인트 이후 지연 로드)
media/        실행 데모 영상 — 전부 스크립트가 브라우저를 몰고 다니며 녹화
media/og.jpg  링크 미리보기 카드 (1200×630)
og.html       그 카드의 원본. 본문과 같은 셰이더·타이포를 쓴다.
              바꾸려면 이 파일을 고치고 1200×630으로 스크린샷해 media/og.jpg로 저장
```

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 열면 일부 브라우저에서 WebGL 컨텍스트가 막히므로 서버로 여는 편이 낫습니다.

## 만든 방식

- 배경 — fbm 노이즈 기반 셰이더. 마우스 위치가 광원, 스크롤과 무관하게 계속 흐릅니다.
- 궤도 — 데스크톱·WebGL 가능일 때만 three를 지연 로드하고, 실패하면 2D 깊이 필드로 되돌아갑니다.
- 데모 영상 — Playwright가 각 사이트를 열어 스크롤·탭 이동을 수행하며 녹화한 뒤 ffmpeg로 인코딩합니다.
- `prefers-reduced-motion`이 켜져 있으면 모든 모션을 끄고 세로 정적 레이아웃으로 바뀝니다.
